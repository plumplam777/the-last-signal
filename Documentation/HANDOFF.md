## 1. The project in short

Diploma 3D first-person narrative puzzle game, **Unity 6.3 (6000.3.10f1), URP, Input System**, macOS (Apple Silicon M4).
Noa Varden answers a distress call from Lantern Station above the ice world Nereth; the station AI **CAIRN** is the only
voice. Docking Bay → Engineering → Medical → Research → Reactor + Command → decision (A destroy & escape / B restore /
C silence, C needs all 14 logs). CAIRN trust 0–100 changes lines, not endings. SQLite accounts, admin panel, saves, EN + BG.
User = solo developer; Claude = technical lead (code, content, docs, decides on subagents).

## 3. How to work on this machine (gotchas)

- Path `/Users/plami/diplomna;3/Last_signal` — the `;` breaks Unity MCP `execute_code`. Use **menu items**
  (`Last Signal/...`), `refresh_unity` (new C# files need scope `all`, mode `force`), `run_tests`, `manage_scene`, `manage_camera`.
- **All content is generated by code.** Edit a builder → refresh → menu `Last Signal/Build Content/Build All Sectors` →
  run tests. Never hand-edit scenes. Builders: `Assets/_Project/Scripts/Editor/*Builder.cs`, data in `*Content.cs`.
- **Props:** `Tools/blender/build_props.py` (headless Blender 5.1, parts authored in Unity coordinates) →
  `Art/Models/Props/*.fbx` → placed by `PropModels.Place(...)` (greybox fallback). Run:
  `/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python Tools/blender/build_props.py -- [--preview <dir>] [--only a,b]`
- **Sky:** `SkyArt.cs` generates Nereth + starfield PNGs (`Art/Textures/Sky`, delete a PNG to regenerate).
- **Audio:** `Tools/generate_voices.py`, `Tools/generate_sfx.py` (both end with `Tools/normalize_audio.py`: voices
  -17 dBFS, ambience -20, per-effect targets). `AudioManager` ducks ambience while someone speaks.
- All player text: `Assets/_Project/Localization/Resources/Localization/{en,bg}.json`. `Loc.Get` of a missing key shows `#key#`.
- Screenshots: positioned `manage_camera` shots with `output_folder: Documentation/Screenshots` (default folder pollutes `Assets/`).
- Quality presets: `Last Signal/Setup/Build Quality Presets` (Low/Medium/High URP assets in `Assets/Settings/Quality`).
  Audio import rules apply automatically (`AudioImportRules`); `Last Signal/Setup/Reimport Audio` after regenerating.
- **Bulgarian font:** Cyrillic comes from the dynamic `LiberationSans SDF - Fallback` asset. Its "Clear Dynamic Data On
  Build" must stay **off** — a build wiped it once and the whole BG UI went blank (TMP exceptions every frame).
  `GlyphRenderTests` catches it. Never commit that asset with an empty `m_GlyphTable`.
- **After every macOS build** run `git diff --stat` on that font asset before committing (see `tmp-fallback-font` memory).
- **Surfaces:** `StationTextures.cs` generates the painted textures (`Art/Textures/Surfaces`, delete a PNG to regenerate);
  `BuilderKit.Box` uses `MetricBox` meshes (UVs in metres). Unity's `Mathf.SmoothStep` is an interpolation, not an
  edge function — use `StationTextures.Smooth()`-style helpers.
- **Anything that moves at runtime** (FlagSpinner, door panels) must not be static: call `BuilderKit.MakeDynamic(go)`
  (`MovingPartsTests`). `FlagSpinner` with an empty flag spins always.
- Reusable art helpers: `Ornament.PanelRow` (framed teal panels), `MedicalBuilder.HatchOrnament` (round hatch surround),
  `Atmosphere.Dust` (room dust motes), `StationMaterials.Painted(mat, maps)`.
- **Screenshots in powered state:** load scene → `manage_editor play` → menu `Last Signal/Debug/Restore Sector Power` →
  `manage_camera screenshot` with `view_position`/`view_target`, `output_folder: Documentation/Screenshots` → `stop`.
  (Command Center sits at y + 20 in `Sector_ReactorCommand`.)
- MCP quirks: `Build All Sectors` may report "Timeout receiving Unity response" but still finishes — check the console
  for `[…Builder] Built …` lines. Don't edit C# while a PlayMode run is going (full PlayMode run ≈ 6 min).
- **Windows build:** quit the editor first (it must restart to see the Windows module), then
  `Unity -batchmode -quit -projectPath … -buildTarget Win64 -executeMethod LastSignal.EditorTools.BuildTools.BuildWindows`,
  reopen with `-buildTarget OSXUniversal`. macOS has no `timeout`; the player quits itself with `-quitAfterSeconds`.
- **Unity in the background freezes Play mode** (no Update while unfocused): after a debug action `sleep 3`, then
  screenshot `PlayerCamera`; `manage_gameobject modify` does not work in Play mode (use debug menus / `Teleport`).
- Smoke-test a build only with `-batchmode -startScene <Scene> -quitAfterSeconds 8 -logFile <scratch>` — **never kill the player**.
- Every MonoBehaviour in a file of the same name. Commit one step at a time, message ends with the session's Co-Authored-By line.
- Tests: 29 EditMode + 103 PlayMode, all green (2026-11-25). Key ones: `DarkDockingTests` (flashlight by spawn, beam-only messages, power relights), `FullPlaythroughTests` (all endings start→menu, Load game in every
  sector, BG run, 14/14 logs), `InteractableReachabilityTests` (props must not bury interactables), `DoorOpeningClearTests`, `WorldTextFitTests`
  (EN+BG), `GlyphRenderTests` (Cyrillic font), `MaterialSanityTests` (no pink), `PerformanceBudgetTests`, `MovingPartsTests`. Spec §16 evidence:
  `Documentation/AcceptanceChecklist.md`.
