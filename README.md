# The Last Signal

First-person sci-fi mystery / puzzle game — Unity 6.3 (6000.3.10f1), URP, C#.

- Spec: `The_Last_Signal_Master_Plan.md`
- Architecture & rules: `Documentation/`
- Story: `Documentation/Narrative/StoryBible.md`

## Open & run
1. Open the folder in Unity Hub with Unity **6000.3.10f1**.
2. Open `Assets/_Project/Scenes/Bootstrap/Bootstrap.unity` and press Play (any scene can also be played directly).
3. Menu **Last Signal/Setup/Run Full Project Setup** recreates missing base scenes and Build Settings.
4. Menu **Last Signal/Build/macOS** builds to `Builds/macOS/`.
